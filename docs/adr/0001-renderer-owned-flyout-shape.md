# Keep the visible flyout in one rendering surface

Win32 window sizing, WebView2 layout and desktop presentation commit independently: rapid view switches reproduced footer jumps and changing top insets even when parent, child and controller dimensions agreed. Linen therefore keeps one fixed transparent host per opening and lets the shared renderer own the panel shape, height, border, corners and shadow. The native shell retains monitor selection, entry/exit, focus and dismissal, with a bounded window region reserved before DOM growth and outside checks against the current panel. This replaces the native DWM shadow with shared CSS styling; returning to native height animation would require a demonstrated common composition boundary, not another geometry acknowledgement.
